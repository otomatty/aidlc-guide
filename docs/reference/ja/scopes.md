# スコープ

## Classic scope（2.9.0）

新規 Classic は 18 / 33 ステージで、Inception から Build and Test までを実行します。Ideation・CI Pipeline・Operation は除外し、既存の記録済みグラフは維持します。深度・テストは Standard、レビューは advisory 1 回、Sensors / Learnings は on、Skeleton / Summary Confirmation は off です。従来の 26 ステージは workshop で選べます。

AIDLC ワークフローのスコープの参照ページです（英語スナップショットの日本語訳）。

詳しくはユーザーガイドの [スコープと深度](../guide/05-scopes-and-depth.md) を参照してください。

## Feature scope

Feature スコープは、Initialization から Operation までの全 33 ステージを含み、既定の深度は Standard です。
