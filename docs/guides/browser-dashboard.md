# ブラウザの Dashboard

> 対象: このマシンのブラウザで Dashboard を見たい人  
> 関連: [非同期 git 共有](./async-sharing.md)（同席できない場合）

## このガイドでできるようになること

Dashboard をこのマシンのブラウザで開く。待受は `127.0.0.1` だけです。

## いつ使うか

| 状況                           | このガイド | 代わり                                 |
| ------------------------------ | ---------- | -------------------------------------- |
| 自分のブラウザで同じ画面を見る | ○          | 拡張の `AIDLC Guide: Open` でも開ける  |
| 時間がずれていて同席できない   | ×          | [async-sharing.md](./async-sharing.md) |

## 前提

- リポジトリで `bun install` 済み
- ワークスペースに有効な Intent / `aidlc/` がある

## 手順: 自分のマシンだけでブラウザ表示

```bash
bun run dashboard
```

ポートを変えるとき:

```bash
bun packages/dashboard-server/src/cli.ts --port 4700
```

期待される結果: `http://127.0.0.1:<port>` で Dashboard が開く。ファイルの変更は画面に反映される。

## docs リンクについて

ブラウザでは IDE のファイルオープンに頼れません。「docs を開く」を使うなら、事前に [ステージ docs の接続先を設定する](./configuring-docs.md) で `stageDocs` または `docsBaseUrl` を入れておく。

## 終了時

共有用プロセスを止める（ターミナルで Ctrl+C）。

## うまくいかないとき

| 症状             | 確認すること                                                               |
| ---------------- | -------------------------------------------------------------------------- |
| ページが開かない | 表示された URL が `127.0.0.1` か、別のプロセスが同じポートを使っていないか |
| 空の Dashboard   | ワークスペースに Intent があるか（サーバの cwd = そのワークスペース）      |
