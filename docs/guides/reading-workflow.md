# Dashboard で現在地と成果物を読む

> 対象: 日常的に AI-DLC の進捗を確認する開発者  
> 関連: [はじめに](./getting-started.md) · [ステージ docs の接続先を設定する](./configuring-docs.md)

## このガイドでできるようになること

Dashboard 上で「今どこか」「次に何を承認するか」「どのユニットがどの成果物を出したか」を読む。

## 画面の見方

### Now strip（上部）

| 表示 | 意味 |
|------|------|
| フェーズ / 現在ステージ | `aidlc-state.md` 上の現在地 |
| 深度（Standard など） | ワークフローの深さ |
| ステータスチップ | completed / awaiting-approval など |
| `done / total` | 進捗 |

アクティブなインテントが無いときは、ここに空状態とインテント一覧への導線が出ます。

### ステージ一覧（左、狭い画面では上）

- フェーズ見出し（INITIALIZATION → … → OPERATION）の下に、実行順のステージが並ぶ  
- 番号付きラベル（例: `1.1 intent-capture`、`4.6 performance-validation`）  
- SKIP も折りたたまず、同じ並びに `skipped` として出る  
- クリックすると詳細パネルが開く（画面幅いっぱい）

### 成果物マトリクス（右、狭い画面では下）

- 行 = ユニット、列 = ステージ  
- セルの件数・`READY` などはサーバが返した値をそのまま表示  
- 「凡例」ボタンでステータス記号の説明をダイアログ表示  
- セルをクリックすると、そのユニット×ステージの成果物ビューアが詳細パネルに載る

### 詳細パネル

- ✕ 閉じる / Esc / 外側クリックで閉じる  
- ステージ解説: 目的・入出力・担当エージェント・ゲート要求  
- 現在ステージなら「次に進むと」コールアウト  
- 「docs を開く」: [config の設定](./configuring-docs.md)に従う  
- 成果物 Markdown: コードフェンスはシンタックスハイライト、`mermaid` は図

### ヘッダーまわり

| 操作 | 内容 |
|------|------|
| インテント | クリックで一覧ダイアログ（切替は `/aidlc intent …`。この画面からは書かない） |
| テーマ | ライト ↔ ダークをワンクリック |
| Live 表示 | 接続状態 / 最終更新 |
| projectLinks | `aidlc-guide.config.json` の追加リンク |

## 典型的な流れ

1. **`AIDLC Guide: Open`** で Dashboard を開く  
2. Now strip でゲート待ちなら、承認すべき内容を確認する  
3. マトリクスで気になるセルを開き、成果物を読む  
4. 用語やステージの意味が分からなければ [MCP / btw](./side-questions.md) に逃がす（本線セッションを汚さない）

## 読取専用であることの意味

Dashboard はワークフロー状態を**書き換えたふりをしません**。

- インテント切替は Claude Code の `/aidlc intent <名前>`  
- ゲート承認・ステージ進行は aidlc-workflows 本体側  
- 例外的な書き込み: 成果物内 `[Answer]:` 行への回答送信、Setup 時の `.mcp.json` マージ

## 狭い画面

幅が狭いときはステージ一覧とマトリクスが縦並びになります。ステージ一覧は件数に応じて伸び、ページ全体でスクロールします。
