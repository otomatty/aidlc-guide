# 開発ルールと工程をカスタマイズする

ヘッダーの「カスタマイズ」から、現在の設定を読み込み、一つの下書きで編集します。フォームで内容を編集し、設定への反映は「変更を確認」から手動で行います。

## 利用できる環境

VS Code / Cursor内のGuideと、同じプロジェクトで起動したローカルブラウザー版が同じ下書きを使います。保存にはBunが必要です。共有用の `--host` モードは現在の設定の閲覧のみです。IDEではワークスペースを信頼していることも必要です。

正式適用には、今回追加したカスタマイズ契約に対応するaidlc-workflowsエンジンが必要です。公開済みの2.8.2にはこの契約はありません。版番号だけで判断せず、導入済みの全ツールの対応状況を確認します。未対応の場合も編集と下書き保存はできますが、設定の適用はできません。

## 編集する

1. 「カスタマイズ」を開き、対象スペースを選びます。
2. カテゴリと項目を選び、フォームで内容を変更します。
3. 入力は約800ミリ秒後に下書きへ保存されます。「下書きを保存」でも保存できます。
4. 「変更を確認」で診断とファイルの差分を読み、内容を確認して「適用」を押します。

| カテゴリ     | 主な編集対象                                                     |
| ------------ | ---------------------------------------------------------------- |
| 開発ルール   | 組織・チーム・プロジェクト・フェーズのルール、ルールファイル設定 |
| ナレッジ     | エージェントが参照する資料、文書原本とDocumentKBの参照           |
| ワークフロー | 工程、スコープ、成果物テンプレート                               |
| エージェント | 担当者の定義、工程への割り当て                                   |
| 品質チェック | センサーの定義、対象、関連するスクリプト                         |
| プラグイン   | 配布名・バージョン・依存関係など                                 |

フォームが扱わない設定は「原文」で編集できます。変更前に戻す操作と、標準定義への変更を解除する操作も用意しています。解析できない原文や参照先が欠けた下書きは保存できますが、修正するまで適用できません。

下書きはプロジェクト全体で一つです。別画面から同時に変更された場合は、自分の入力と保存済みの内容を比較して取り込みます。設定をIDEなどで直接変更した場合も、下書きの基準を比較して更新します。

## 他のプロジェクトへ配布する

「書き出す」で項目と配布形式を選びます。

| 形式                  | 用途                                                                     |
| --------------------- | ------------------------------------------------------------------------ |
| Guide用の設定ファイル | ルールの章などを含め、Guide同士で設定を移す                              |
| 標準プラグインのZIP   | 標準プラグインで表現できる追加定義と、選択したツール向けの出力を配布する |

標準プラグインで表現できない設定は表示され、除外を確認してから書き出します。必要な依存先を選択していない場合は、診断に従って選択を見直してください。

受け取ったGuide用ファイルは「読み込む」で比較し、必要な項目と取り込み先を選びます。選んでいない項目やほかの下書き編集は保持されます。取り込みは下書きへの変更なので、その後に差分を確認して適用します。

## 適用と復旧

変更は今後開始するワークフローに使います。設定を共有するスペースに未完了の作業がある間は適用できません。一時停止、承認待ち、単独工程、構成案の確認待ちも対象です。下書きの編集と保存は続けられます。

適用の応答が途切れた場合は結果を再確認します。「復旧が必要」と表示された場合は、画面から復旧操作を行ってください。設定ファイルや復旧記録を手動で削除せず、同じ適用操作の結果を確定させます。

検証と差分生成は設定の整合性を調べる処理です。試行用ワークフローを起動したり、センサーや任意のプラグイン処理を実行したりする機能はありません。

下書き・受付記録は `aidlc/guide-customization/.local/`、適用の復旧記録は `aidlc/.aidlc-customization/` に保存され、Gitの対象外です。適用済みの変更定義とプロジェクトのルール・資料はGitで共有できます。
