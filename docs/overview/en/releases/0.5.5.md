## [0.5.5] - 2026-06-01

Bumps the shipped framework's default orchestrator model from Opus 4.7 to Opus 4.8 (`us.anthropic.claude-opus-4-8`), still run at the 1M-context variant (`opus[1m]`) via AWS Bedrock. No upgrade action required if you use the shipped `.claude/settings.json`; if you pin the model in your own `.claude/settings.local.json`, update `ANTHROPIC_DEFAULT_OPUS_MODEL` to pick up 4.8. Requires Bedrock model access for `us.anthropic.claude-opus-4-8`.

* `ANTHROPIC_DEFAULT_OPUS_MODEL` in the shipped `.claude/settings.json` is now `us.anthropic.claude-opus-4-8` (was `...-4-7`); the Sonnet and Haiku defaults are unchanged.
* Getting-started env-var table and the shipped `CLAUDE.md` Bedrock prerequisite updated to name Opus 4.8.
