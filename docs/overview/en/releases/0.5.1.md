## [0.5.1] - 2026-05-31

`aidlc-runtime.ts` gains a `summary` subcommand that prints deterministic aggregates over `runtime-graph.json` — stage/phase outcome tallies, memory-entry counts by category, sensor 4-state tallies, learnings captured, and workflow duration. This is the first step of the session-tooling recomposition: the read-only session skills (session-cost, replay, outcomes-pack — landing in a later release) will consume the `--json` shape so every number they render comes from the data plane, not from LLM-side prose counting. Read-only; no audit emit; no behavioural change to any existing surface. No upgrade action required.

* `aidlc-claude-code/.claude/tools/aidlc-runtime.ts` — new `summary [--json]` subcommand. Reads `runtime-graph.json`, flattens `instances[]` per stage, and tallies stage outcomes (approved/failed/pending), per-phase rollups, memory entries by canonical heading, sensor results (passed/failed/budget-override/incomplete), and `learnings_captured`. `duration_minutes` spans first start to latest completed (null on pending-only workflows). Missing `runtime-graph.json` exits 1. Human-readable render by default; machine shape behind `--json`.
* `tests/feature/t106-runtime-summary.sh` (new) — behavioural contract for `summary`: outcome aggregation, phase rollup, memory tallies, duration computation, `--json` determinism, and the missing-graph exit-1 case.
* `aidlc-claude-code/.claude/tools/aidlc-version.ts` — bumped 0.5.0 → 0.5.1.
