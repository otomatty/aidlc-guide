## [0.5.8] - 2026-06-02

Adds the first piece of the deterministic orchestration engine — a new internal `aidlc-orchestrate next` command. It reads your workflow state and the compiled stage graph and prints exactly one typed "directive" (JSON) describing the single next move, mutating nothing. This is groundwork only: the engine stands beside the prose orchestrator and nothing in the workflow calls it yet, so your `/aidlc` runs are completely unchanged. No upgrade action required.

* New internal command `bun .claude/tools/aidlc-orchestrate.ts next [--project-dir <dir>] [--scope <scope>] [--stage <slug>] [--phase <name>]` prints one validated directive to stdout and exits. It is read-only — it never writes state, never asks questions, and never spawns agents. Scope resolves by precedence: an existing state file's scope wins, then `--scope`, then `AWS_AIDLC_DEFAULT_SCOPE`, then the default. Read-only flags (`--status`/`--help`/`--doctor`/`--version`) and the mutually-exclusive `--stage`+`--phase` combination map to terminal directives. The companion `report` subcommand is reserved and returns a clear not-implemented message for now.
