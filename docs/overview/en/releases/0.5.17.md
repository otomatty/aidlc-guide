## [0.5.17] - 2026-06-04

Moves scope membership off the hand-edited `tools/data/scope-mapping.json` blob onto the same file-authored pattern every other primitive already uses. A scope is now authored as one `.claude/scopes/aidlc-<name>.md` file (frontmatter `name`/`depth`/`keywords`/`description`, prose body) plus a per-stage membership tag: each stage's frontmatter carries a `scopes: [<name>, …]` list naming the scopes under which it runs. The build step `bun .claude/tools/aidlc-graph.ts compile` transposes those per-stage lists into the EXECUTE/SKIP grid (`.claude/tools/data/scope-grid.json`, a new compiled artifact drift-guarded by `compile --check` exactly like `stage-graph.json`), and the runtime resolves scopes from the grid + the `.md` files instead of the JSON. Behaviour is unchanged — every scope resolves and runs exactly as before (proven byte-identical across all 9 scopes by an `AIDLC_GRAPH_RESOLVE=1` parity test) — and `tools/data/scope-mapping.json` is deleted. Adding a scope is now the same muscle memory as authoring a sensor or agent: drop `.claude/scopes/aidlc-<name>.md` and tag the stages; no code change. Upgrade action: customisers who edited `scope-mapping.json` should re-express those choices as `.claude/scopes/*.md` files plus per-stage `scopes:` tags, then run `compile` to regenerate the grid.

* Scopes are now authored as `.claude/scopes/aidlc-<name>.md` files (one per scope) plus a `scopes:` list in each stage's frontmatter. Dropping a new `.claude/scopes/aidlc-x.md` makes `x` a valid scope — `/aidlc --scope x`, `/aidlc --doctor`, and NL keyword inference all pick it up with no code change.
* `bun .claude/tools/aidlc-graph.ts compile` now emits a second compiled artifact, `.claude/tools/data/scope-grid.json` (the EXECUTE/SKIP transpose). `compile --check` fails (exit 1) if either `stage-graph.json` or `scope-grid.json` is stale.
* New `bun .claude/tools/aidlc-graph.ts resolve <scope>` subcommand emits the active scope's plan (`.aidlc-plan.json`); it is gated behind `AIDLC_GRAPH_RESOLVE=1` during rollout.
* `tools/data/scope-mapping.json` is removed. Any script reading that file directly must read `tools/data/scope-grid.json` (same `{scope: {stages}}` shape) for the EXECUTE/SKIP grid, or the `.claude/scopes/*.md` frontmatter for depth/keywords/description.
