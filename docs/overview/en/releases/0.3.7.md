## [0.3.7] - 2026-05-18

Bumps the state-template version from 6 to 7 and adds three new fields used by downstream worktree and practices work: `Worktree Path` (set when a Bolt forks state into a worktree), `Bolt Refs` (active Bolt slugs for cleanup), `Practices Affirmed Timestamp` (ISO 8601 stamp written on the practices-discovery affirmation gate). Doctor now fails loud on v6 state files with archive-and-reinit advice. **No migration code** — following the v5→v6 precedent at commit `c084c2c`. v6 users archive their workspace (`mv aidlc-docs aidlc-docs.v6-archive`) and re-run `/aidlc --init` to scaffold v7.

* `bun .claude/tools/aidlc-utility.ts version` prints `aidlc 0.3.7`
* Fresh `/aidlc --init` produces a v7 state file with `Worktree Path`, `Bolt Refs`, `Practices Affirmed Timestamp` fields present (empty by default until populated)
* `/aidlc --doctor` exits non-zero on a v6 state file with the message `state version current — v${match[1]} state detected. Archive your workspace and re-run /aidlc --init to scaffold a v7 workspace.` On a malformed or missing State Version line, doctor reports `state version readable` failure with the same archive-and-reinit advice
* 9 of 10 state fixtures bumped (`tests/fixtures/state-corrupted.md` retained at v6/empty for parse-failure tests). 6 test grep assertions updated (t12, t21, t50, t52, t70, t71)
* `docs/reference/02-orchestrator.md` State File Schema description updated to reference State Version 7 + the 3 new Project Information fields
