## [0.6.6] - 2026-06-11

Refreshes the shipped Bedrock model aliases so accounts using global inference profiles have the same path across the model family. The orchestrator still defaults to `opus[1m]`; Fable is now pinned for users who opt into `fable`/`fable[1m]`, and Sonnet plus Haiku move from `us.` to `global.` profile IDs. Re-copy the shipped `.claude/` or edit your existing `.claude/settings.json` model aliases to pick this up.

* `dist/claude/.claude/settings.json` — adds `ANTHROPIC_DEFAULT_FABLE_MODEL=global.anthropic.claude-fable-5`, changes `ANTHROPIC_DEFAULT_SONNET_MODEL` to `global.anthropic.claude-sonnet-4-6`, and changes `ANTHROPIC_DEFAULT_HAIKU_MODEL` to `global.anthropic.claude-haiku-4-5-20251001-v1:0`.
* `docs/guide/01-getting-started.md` and the shipped `.claude/CLAUDE.md` — document the Fable alias and the global Bedrock profile defaults.
