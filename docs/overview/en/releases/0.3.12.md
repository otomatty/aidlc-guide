## [0.3.12] - 2026-05-19

The SKILL.md Construction-flow rewrite — the most user-facing change of the release. The orchestrator now reads team practices once at Construction start (`extractMarkdownSection` over `team.md → org.md → hardcoded defaults` per `aidlc-knowledge/shared/practices-reading.md`), drives a parallel-batch dispatch model with explicit phase contracts (Phase 0 worktree creation in one assistant message, Phase 1+2 per-Bolt serial Q+A, Phase 3 parallel `Task` invocations pinned via prompt path, Phase 4 batch-level approval gate, Phase 5 N parallel `aidlc-bolt complete --merge` calls), and brackets every pipeline-deploy-agent dispatch with `MERGE_DISPATCH_INVOKED` (pre-call) and either `MERGE_DISPATCH_RETURNED` or `MERGE_DISPATCH_FALLBACK` (post-call) audit rows via the new `aidlc-bolt dispatch-event` subcommand. Walking-skeleton stance is now dynamic — read from `practices/team.md`'s `## Walking Skeleton` section with scope-mapping fallback for unaffirmed teams; bolt-plan-marker-vs-practices conflicts emit `PRACTICES_OVERRIDE` with `Reason: bolt-plan-marker-conflict` (discriminator-field disambiguation, not a new event — t28 stays at 55). Halt-and-ask gains explicit multi-failure semantics: when ≥2 Bolts in a parallel batch fail, AUQs render sequentially in slug order, ALL successful Bolts hold their merge-dispatch via a `Merge-Held: true` per-Bolt-state marker until every failed AUQ resolves. Two new italic carve-outs document the audit-merge prefix-hash mismatch failure mode and the orphan-BOLT_STARTED recovery seam. Ten agents now cite `aidlc-knowledge/shared/practices-reading.md` in their Knowledge Loading sections.

* `bun .claude/tools/aidlc-bolt.ts dispatch-event --event MERGE_DISPATCH_INVOKED --slug <kebab-slug> --practices-excerpt "<text>"` — new subcommand for the orchestrator's pre-call dispatch instrumentation. Audit-of-intent semantic: emit precedes the `Task(pipeline-deploy-agent, ...)` LLM call. Reconciled by doctor via slug + timestamp window (no correlation tag — the LLM call has no disk artifact to sequence against)
* `bun .claude/tools/aidlc-bolt.ts dispatch-event --event MERGE_DISPATCH_RETURNED --slug <slug> --strategy <squash|merge|rebase> --target <branch> --confidence <0-1> --notes "<text>"` — post-call emit on a parsable JSON envelope from pipeline-deploy-agent. Validates `--strategy` enum and `--confidence` range
* `bun .claude/tools/aidlc-bolt.ts dispatch-event --event MERGE_DISPATCH_FALLBACK --slug <slug> --reason <enum> --defaults "<text>"` — post-call emit on timeout, malformed YAML, or low-confidence return; orchestrator proceeds with org.md defaults. Critical observability hook for "we silently used trunk defaults instead of the team's affirmed strategy"
