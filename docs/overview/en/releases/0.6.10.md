## [0.6.10] - 2026-06-13

Restructures the repository to the one-core-three-harnesses layout (dist-unified keystone). The hand-authored source now lives in `core/` (harness-neutral: tools, stages, agents, rules, knowledge, hooks) and `harness/claude/` (the orchestrator skill, CLAUDE.md, settings); `bun scripts/package.ts` regenerates `dist/claude/` from them, and `bun scripts/package.ts --check` is the byte-parity drift guard. The shipped `dist/claude/.claude/` is byte-identical to the previous release — re-copy it as before; this release moves where maintainers edit, not what you install.

* No user-facing command, flag, or behavior change — `dist/claude/.claude/` is regenerated byte-for-byte identical to 0.6.9.
* Contributors now edit `core/` (or `harness/claude/`) and run `bun scripts/package.ts`; hand-editing `dist/` fails the new `package.ts --check` drift guard in CI. See `docs/reference/11-contributing.md`.
* Core `.md` prose carries a `{{HARNESS_DIR}}` token that the packager substitutes per harness; truthful Claude-specific references (the `$CLAUDE_PROJECT_DIR` note, the harness-dir enumeration in workspace-detection) stay literal.
