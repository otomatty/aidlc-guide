## [0.3.1] - 2026-05-15

Adds a runtime version surface so `/aidlc --version` prints the framework version, and formalises the per-release changelog cadence.

* `/aidlc --version` prints the framework version (e.g. `aidlc 0.3.1`). Equivalent to `bun .claude/tools/aidlc-utility.ts version`. Like `--status`, `--help`, and `--doctor`, it runs without a workflow and never prompts to resume one
* Every user-visible release now bumps the version and adds a matching `## [X.Y.Z]` heading to `CHANGELOG.md` in the same commit, replacing the prior release-cut-time policy. Pure doc sweeps and internal refactors don't bump. Tagging (`git tag vX.Y.Z`) remains a post-merge ritual, not a CI gate. Pinned by `tests/unit/t68-version-changelog-sync.sh`
