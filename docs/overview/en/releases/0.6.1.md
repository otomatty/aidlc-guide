## [0.6.1] - 2026-06-08

Normalizes the path strings the compiled stage graph records for rules and sensors to POSIX form (forward slashes) on every platform. On macOS and Linux this is a no-op — the emitted paths are byte-identical to before. On Windows the compiled graph previously recorded backslash paths in each stage's `rules_in_context` / `sensors_applicable` rows, which mismatched any forward-slash comparison; they are now consistent with the rest of the framework. No upgrade action; re-copy the shipped `.claude/` to pick it up.

* `dist/claude/.claude/tools/aidlc-lib.ts` — adds an exported `toPosix(path)` helper (a no-op when the OS separator is already `/`).
* `dist/claude/.claude/tools/aidlc-graph.ts` — the `.claude/rules` and `.claude/sensors` path-emit sites in `loadRules` / `loadSensors` now pass through `toPosix`, so the compiled graph's resolution rows are POSIX-form on Windows as on macOS/Linux.
