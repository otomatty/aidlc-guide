## [0.3.4] - 2026-05-17

Adds the `worktree` test tier — a new dispatch surface in `tests/run-tests.sh`, four shell helpers in `tests/lib/worktree-helpers.sh`, and a meta-test under `tests/worktree/`. Downstream consumers — `aidlc-worktree.ts`, state fork/merge, audit fork/merge, `aidlc-bolt` worktree subcommands — populate the tier with real coverage; on day one it ships with a single 7-assertion meta-test that pins the helper contract.

* `bash tests/run-tests.sh --worktree` runs the new tier. Joined into `--ci`, `--release`, and `--all` profiles so CI gates don't silently skip worktree coverage as consumers land. No LLM dependency — fires after the preflight gate. Pinned to serial in `run_tier` until parallelism is proven safe under interleaved `git worktree` registry mutations
* `tests/lib/worktree-helpers.sh` exports `setup_worktree_fixture`, `assert_worktree_at`, `assert_worktree_absent`, `cleanup_worktree_fixture`. Setup creates a per-test `mktemp` git repo with one seed commit on `main` (uses `git init -q` + `git symbolic-ref` for git ≥ 2.5 portability — `git init -b` requires 2.28). Failure-loud: any setup step failing returns 1 and removes the partial fixture. Cleanup is idempotent and refuses to act on paths whose basename does not start with `aidlc-worktree-` — defence-in-depth so `cleanup_worktree_fixture ""` or a typo can't `rm -rf` `/`, `$HOME`, or other system paths
* `tests/worktree/t01-helpers.sh` (7 assertions) exercises the helpers against a fresh fixture and probes the cleanup-guard's path-prefix check with a sentinel directory
* `tests/smoke/t05-run-tests-parallel.sh` extended (plan 11 → 14) to cover `--worktree` dispatch under direct invocation and via `--ci`. `tests/feature/t55-test-suite-drift.sh` `TIERS` array updated so the drift sweep walks the new tier
