## [0.4.2] - 2026-05-22

**BREAKING — framework rename + flat rules layout + practices folder removed.** Three structural reorgs ship together. (1) All framework-shipped files in extension-point directories now carry an `aidlc-` filename prefix so users distinguish framework files from their own at a glance — three tools (`aidlc-lib.ts`, `aidlc-stage-schema.ts`, `aidlc-version.ts`), six hooks (the `aidlc-audit-logger.ts` / `aidlc-log-subagent.ts` / `aidlc-session-end.ts` / `aidlc-session-start.ts` / `aidlc-sync-statusline.ts` / `aidlc-validate-state.ts` set), eleven agents (the `aidlc-<role>-agent.md` set), plus the `.claude/aidlc-knowledge/` directory renamed to `.claude/knowledge/` with each per-agent subdirectory gaining the `aidlc-` prefix. (2) `.claude/rules/aidlc/{guardrails,phases}/` flattens to `.claude/rules/aidlc-{org,team,project,phase-<phase>}.md` — three scope-layer files plus four phase-scoped files, all in one flat directory. The team layer (`aidlc-team.md`) is genuinely new — populated by practices-discovery's affirmation gate. (3) `.claude/practices/` is removed entirely; team-authored harness config now lives in the same `.claude/rules/` namespace as guardrails, with a section mapping that folds `## Branching` / `## Testing posture` / `## Deployment cadence` / `## Code style` into `## Way of Working` / `## Testing Posture` / `## Deployment` / `## Code Style`.

Migration: customisations under `.claude/practices/` or `.claude/rules/aidlc/guardrails/` re-target to `.claude/rules/aidlc-<scope>.md`. Hand-authored hooks pinning old hook filenames need rename. Users mid-workflow archive `aidlc-docs/` and re-init per the existing pre-1.0 no-migration policy.

* **Framework filenames carry `aidlc-` prefix** across `tools/`, `hooks/`, and `agents/`. The 20 file renames preserve git history via `git mv`. The shipped `.claude/CLAUDE.md` reflects the new prefix discipline.
* **`aidlc-knowledge/` → `knowledge/`** with per-agent subdirectories renamed `aidlc-<role>-agent/` (11 directories, 55 knowledge files relocate). The `shared/` subdirectory also gains the prefix → `aidlc-shared/` so framework-shipped files stand apart from team-authored ones at a glance; `--init` scaffolds `aidlc-docs/knowledge/aidlc-shared/` to match. `practices-reading.md` renamed to `rules-reading.md`; agent Knowledge Loading entries cite the new filename.
* **Flat rules layout** at `.claude/rules/`: seven files total (`aidlc-org.md`, `aidlc-team.md`, `aidlc-project.md`, `aidlc-phase-construction.md`, `aidlc-phase-ideation.md`, `aidlc-phase-inception.md`, `aidlc-phase-operation.md`). The phase files retain their `paths:` frontmatter; the scope files derive scope from filename pattern.
* **Practices folder removed.** `aidlc-state.ts practices-promote` writes to `.claude/rules/aidlc-team.md` (section-replace × 5: Way of Working / Walking Skeleton / Testing Posture / Deployment / Code Style) and `.claude/rules/aidlc-project.md` (append-under-heading × 2: Mandated / Forbidden). Behavioural changes you'll see: `bun aidlc-state.ts practices-promote` errors mention `aidlc-team.md` / `aidlc-project.md` instead of the old paths; `practices-discovery` stage prose presents the new heading set in the AskUserQuestion options.
* **`bun .claude/tools/aidlc-guardrail.ts`** writes to the flat layout — `--scope project` writes `.claude/rules/aidlc-project.md`; `--scope org` writes `.claude/rules/aidlc-org.md`.
* **Settings + skill hooks** updated. `.claude/settings.json` SessionStart/SessionEnd hooks point at the new prefixed filenames. `.claude/skills/aidlc/SKILL.md` PostToolUse / PreCompact / SubagentStop hook entries match.
* **Stripped release-version markers** from framework code. Comments under `aidlc-claude-code/.claude/` describe what code does, not which release added it. Version content remains in `aidlc-version.ts` and `CHANGELOG.md` because version is their domain. The `Reserved` placeholder cells in `audit-format.md` are now bare `Reserved` tokens; downstream consumers flip the cells to actual emitter paths.
* **Test fixtures + assertions** rewired. `t75-practices-promote.sh` builds the new layout in its fixture and asserts on the new heading set. The `t55-test-suite-drift.sh` extension catches stale `aidlc-knowledge/`, `.claude/practices/`, and `rules/aidlc/` strings if any are reintroduced.
