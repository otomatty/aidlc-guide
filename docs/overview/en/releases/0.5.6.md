## [0.5.6] - 2026-06-02

Relocates the shipped framework from `aidlc-claude-code/` to `dist/claude/` (history-preserving move). The shipped directory is still `.claude` (with the dot) — only the source-repo wrapper changed. **Upgrade action:** the install command is now `cp -r dist/claude/.claude/ your-project/.claude/` (was `cp -r aidlc-claude-code/.claude/ your-project/.claude/`); update any scripts or docs that referenced the old path. No change to the framework's runtime behaviour.

* The distributable now lives at `dist/claude/.claude/`; copy it in with `cp -r dist/claude/.claude/ your-project/.claude/`.
* The `isFrameworkDistributionPath` guard (which refuses to scaffold a learnt sensor manifest into the framework tree) now recognises the relocated `dist/claude/.claude/sensors` path; a new `t112-learnings-distribution-guard.sh` pins it.
* Removed the stale `dist/` entry from `.gitignore` so the relocated framework is tracked (it guarded build output the repo never produced).
