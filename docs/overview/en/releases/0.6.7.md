## [0.6.7] - 2026-06-12

Hardens the engine handoff after live `/aidlc` runs exposed recovery paths a human conductor can naturally hit. Stage reports can now pin the acted directive with `--stage <slug>`, recover a missing approval gate before approving, and treat a completed workflow re-report as idempotent. Runtime graph refresh and summary output now follow the public `report` path and reconcile completed state so session summaries do not show stale pending counts after recovery. Re-copy the shipped `.claude/` to pick it up.

* `dist/claude/.claude/tools/aidlc-orchestrate.ts` — `report` uses `--stage <slug>` for the acted stage, opens a missing gate before approval on explicit-stage reports, advances a manually completed active stage, and returns an idempotent `done` when the workflow is already complete.
* `dist/claude/.claude/hooks/aidlc-runtime-compile.ts` and `dist/claude/.claude/tools/aidlc-runtime.ts` — runtime compile now watches `aidlc-orchestrate.ts report`, and `summary` reconciles completed `aidlc-state.md` checkboxes over stale or incomplete runtime graph rows.
* `dist/claude/.claude/skills/aidlc/SKILL.md`, scope runners, and `aidlc-common/protocols/stage-protocol.md` — conductor guidance now reports approvals with `--stage <directive.stage>` and leaves forward transition bookkeeping to the engine.
