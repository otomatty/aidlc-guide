## [0.6.5] - 2026-06-10

Moves the framework's default Opus model from the US-regional Bedrock inference profile to the global one, and teaches the statusline to abbreviate every Bedrock profile prefix. Under Bedrock's account-level data retention modes, an account set to `provider_data_share` (required for Claude Fable 5) can no longer invoke `us.anthropic.claude-opus-4-8` — requests fail with a Bedrock `InternalServerException` — while the `global.` profile works under every retention mode. If your account uses `provider_data_share`, re-copy the shipped `.claude/` (or edit `ANTHROPIC_DEFAULT_OPUS_MODEL` in your existing `settings.json`) to pick this up; accounts on the `default` retention mode work with either profile.

* `dist/claude/.claude/settings.json` — `ANTHROPIC_DEFAULT_OPUS_MODEL` is now `global.anthropic.claude-opus-4-8` (was `us.anthropic.claude-opus-4-8`).
* `dist/claude/.claude/hooks/aidlc-statusline.ts` — `abbreviateModel` recognises all Bedrock inference-profile prefixes (`us.` / `eu.` / `apac.` / `global.`), so the statusline renders `BR:opus-4-8[1m]` for the global profile instead of the unabbreviated model id.
