## [0.6.11] - 2026-06-13

Adds the Kiro CLI distribution to the one-core-three-harnesses build: `harness/kiro/` (manifest + the Kiro-authored orchestrator skill, agent JSON configs, the `aidlc-kiro-adapter.ts` stdin shim, `settings/cli.json`, and `AGENTS.md`) now regenerates `dist/kiro/` from the shared `core/` via `bun scripts/package.ts kiro`. Install Kiro by copying `dist/kiro/.kiro/` (and `dist/kiro/AGENTS.md`) into your project, exactly as before.

* `bun scripts/package.ts` now regenerates `dist/kiro/` alongside `dist/claude/`; `--check` drift-guards both. The packager gained a rules-dir rename (Kiro: `rules/` → `steering/`) and project-root file placement (AGENTS.md).
* New deterministic tests: `t147-kiro-hook-adapter` (the stdin-shim contract against live-captured payloads) and `t148-kiro-file-structure` (dist/kiro structural smoke). The Kiro ACP + TUI journeys ship as e2e that skip cleanly without `AIDLC_KIRO_ACP_LIVE=1` / `AIDLC_KIRO_TUI_LIVE=1` and a logged-in `kiro-cli`.
* No change to the Claude distribution — `dist/claude/.claude/` stays byte-identical.
