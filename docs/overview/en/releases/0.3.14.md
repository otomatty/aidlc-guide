## [0.3.14] - 2026-05-20

Doctor extensions for the worktree / state-fork / audit-fork / practices surfaces. Six new sequential check rows insert into `aidlc-utility.ts` `handleDoctor()` between the existing state-version block and the graph-level checks (Check 4 internally covers three reconciliation surfaces — orphan AUDIT_FORKED-without-disk, orphan-delta drift, and PRACTICES_OVERRIDE Reason discriminator routing — under one row label). Each check is read-only and pushes onto the same `results` accumulator existing checks use; doctor preserves its single existing `appendAuditEvent("HEALTH_CHECKED")` row at handler exit unchanged. Threshold constants `PRACTICES_STALENESS_DAYS = 90` and `MERGE_DISPATCH_TIMEOUT_SEC = 60` are tagged for v0.5.0+ relocation to `practices/team.md` and per-stage Sensors-compartment binding parameters. Two reconciliation surfaces explicitly deferred to v0.5.0+: orphan `Merge-Held: true` markers (requires net-new doctor capability — walk per-Bolt forked state + parent-batch BOLT_FAILED resolution graph, with workshop-resume false-positive guard per `SKILL.md:735`) and workshop `git ls-remote` stale-claim detection (remote-aware doctor composes with the post-1.0 visual-designer offline-mode story). Both deferrals carry forward-note comments in source pointing at the v0.5.0+ implementer.

* `bun .claude/tools/aidlc-utility.ts doctor` — six new check rows print between "State Version: 7" and "Cycle detection: 0 cycles":
  * `Orphan worktrees: N` — walks `.aidlc/worktrees/bolt-*/`, classifies each as active fork (slug in main `Bolt Refs` → ✓), preserved-by-abort (slug in Bolt Refs + `BOLT_FAILED` row carries `Reason: aborted` — multi-failure AUQ aborted at index k, awaiting `/aidlc --resume`), cleanup-orphan (WORKTREE_MERGED landed or `[merge-succeeded:<sha>]` ERROR_LOGGED tag — directory persists), or unmatched (no audit trail). Reports `0 worktrees observed` with pass=true on a fresh project, a fail-clean guarantee
  * `Stale branches: N` — runs `git branch --list 'bolt-*'`, flags any `bolt-<slug>` branch whose worktree directory is gone but no terminal WORKTREE_DISCARDED / WORKTREE_MERGED audit row landed. Skips silently on non-git-repo paths (smoke / fresh fixtures)
  * `Orphan state files: N` — walks `<wt>/aidlc-docs/aidlc-state.md`, flags any worktree state file whose slug is not in main's `Bolt Refs` and has no WORKTREE_DISCARDED pairing
  * `Orphan audit: N` — three reconciliation surfaces under one row: (a) AUDIT_FORKED-without-disk-state (no `<wt>/aidlc-docs/audit.md` on disk; only fires when no terminal pairing exists, so a successfully-merged-and-cleaned Bolt with AUDIT_MERGED in main does NOT flag), (b) orphan-delta (no matching AUDIT_MERGED, no active fork, no WORKTREE_DISCARDED), (c) PRACTICES_OVERRIDE Reason discriminator routing per `audit-format.md:138` (write-failure-* without follow-up PRACTICES_AFFIRMED → flagged via `Date.parse()` ms comparison so millisecond-precision AFFIRMED satisfies seconds-precision OVERRIDE; bolt-plan-marker-conflict → expected behaviour, not flagged; unknown Reasons → tracked in advisory count for v0.5.0+ reconciliation)
  * `Practices staleness: N days ago` — reads `Practices Affirmed Timestamp` from main state and compares to now. Empty / missing / template-default → informational pass; within 90 days → pass with day count; older → advisory pass=true (does NOT fail exit code); future-dated (clock skew or hand-edit) → advisory pass with explanatory label; invalid ISO 8601 string → fail readable
  * `MERGE_DISPATCH: N orphan INVOKED` — advisory pass=true. Pair-matches per slug: each terminal row (RETURNED or FALLBACK) consumed by at most one preceding INVOKED in chronological order, so two INVOKED + one RETURNED for the same slug correctly reports one orphan. The v0.10.0 cross-workflow observer + ralph driver takes over LLM-dispatch-timeout reconciliation
* `lib.ts` gains four new exports — `findAllEvents(audit, event, slug?)` (multi-match audit-walker; mirrors `findLatestEvent`'s signature; normalises CRLF → LF before splitting on the `\n---\n` block separator so audits authored or edited on Windows parse identically to Unix), `SLUG_TAG_REGEX` (`\[slug=([a-z0-9-]+)\]`), `FORK_EMITTED_TAG_REGEX` (`\[fork-emitted:([^\]]+)\]`), `MERGE_SUCCEEDED_TAG_REGEX` (`\[merge-succeeded:([^\]]+)\]`). Promotes the slug correlation tags from inline literals at `aidlc-worktree.ts:787-792` / `aidlc-audit.ts:301,385` / `aidlc-state.ts:1538` to a single shared definition so v0.5.0+ sensors and v0.8.0 observers reuse one regex
* `aidlc-utility.ts` exports `PRACTICES_STALENESS_DAYS = 90` and `MERGE_DISPATCH_TIMEOUT_SEC = 60`. Both tagged for v0.5.0+ relocation
* `aidlc-bolt.ts` near `handleHoldMerge` carries a forward-note comment naming the orphan `Merge-Held: true` reconciliation deferred to v0.5.0 doctor — walk per-Bolt forked state for held flag, cross-check parent batch's BOLT_FAILED resolution status, flag if all siblings resolved but `release-merge` never ran. Workshop-resume false-positive guard required per `SKILL.md:735`
