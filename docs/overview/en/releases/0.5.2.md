## [0.5.2] - 2026-05-31

Three read-only session skills become typeable: `/aidlc-session-cost`, `/aidlc-replay`, and `/aidlc-outcomes-pack`. Each pulls every count — stage outcomes, per-phase rollup, memory entries, sensor firings, learnings, duration — from `aidlc-runtime.ts summary --json` (shipped in 0.5.1) rather than counting by reading files. They are classified `read-only`: none advances the workflow stage pointer and none emits an audit event. `/aidlc-session-cost` and `/aidlc-replay` print to the terminal only; `/aidlc-outcomes-pack` is the only one that writes a file (`OUTCOMES.md`). The previous design's `characters ÷ 4` token estimate is dropped, not ported — token guesswork from file sizes is gone. No upgrade action required; the new skills appear in the `/` skill picker on next session.

* `aidlc-claude-code/.claude/skills/aidlc-session-cost/SKILL.md` (new) — read-only cost view; renders the `summary --json` fields verbatim, prints no token estimate, writes no file.
* `aidlc-claude-code/.claude/skills/aidlc-replay/SKILL.md` (new) — read-only session narrative; counts from `summary --json`, prose from `audit.md` + artefacts; renders to the terminal, writes no file.
* `aidlc-claude-code/.claude/skills/aidlc-outcomes-pack/SKILL.md` (new) — read-only handover doc; counts from `summary --json`, content from artefacts + delivered code; writes `OUTCOMES.md` (the only session skill that writes a file).
* `tests/feature/t107-session-skills-readonly.sh` (new) — asserts frontmatter (`name` / `user-invocable` / `classification: read-only`), `summary --json` sourcing, no retired token heuristic, no audit/state-advance, and that only outcomes-pack writes a file.
* `aidlc-claude-code/.claude/CLAUDE.md` — documents the three session skills under AI-DLC Structure.
* `aidlc-claude-code/.claude/tools/aidlc-version.ts` — bumped 0.5.1 → 0.5.2.
