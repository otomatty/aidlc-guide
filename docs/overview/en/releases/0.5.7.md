## [0.5.7] - 2026-06-02

Pre-registers the five swarm-lifecycle audit events as reserved registry rows ahead of the swarm executor. This is a paperwork-only change: the event names are now valid (the audit CLI accepts a `SWARM_*` event and the registry, headings, and docs all know about them) but nothing emits them yet — the emitters are wired with `aidlc-swarm.ts` in a later release. No behaviour change; no upgrade action required.

* New reserved audit events `SWARM_STARTED`, `SWARM_UNIT_CONVERGED`, `SWARM_UNIT_FAILED`, `SWARM_BATON_RETURNED`, and `SWARM_COMPLETED` are now accepted by `bun .claude/tools/aidlc-audit.ts append <EVENT>`; they have no emitters yet (Reserved rows), so they will not appear in any workflow's `audit.md` until the swarm executor ships.
* Audit registry count moves from 61 to 66 events (17 to 18 categories); the `tests/unit/t28-audit-event-sync.sh` count pin and the `audit-format.md` / `12-state-machine.md` / `09-state-and-audit.md` taxonomy tables are bumped in lockstep.
