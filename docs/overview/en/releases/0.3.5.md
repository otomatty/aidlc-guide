## [0.3.5] - 2026-05-17

Configuration-layers documentation, `.claude/practices/` namespace, and a five-strategy branching-strategies knowledge file. These deliverables are scaffolding consumed by later work; they exercise no user-facing surface yet but ship a new top-level `.claude/practices/` directory and a new architecture chapter section that contributors will route through.

* New "Configuration layers" section in `docs/reference/01-architecture.md` documents the two-axis routing model (authorship × consumption) for placing new concerns in `.claude/` and `aidlc-docs/`. Four quadrants — three populated, one intentionally empty. Boundary tests, sub-categories of harness config, and a callout for practices-discovery's cross-row promotion. Anchors v0.5.0+ routing decisions
* New `.claude/practices/` namespace: `org.md` (framework methodology defaults written in team-voice), `team.md` (empty template populated by practices-discovery affirmation), `project.md` (empty override template). Loaders read in order org → team → project; later layers replace earlier
* New `.claude/aidlc-knowledge/pipeline-deploy-agent/branching-strategies.md` covering trunk-based, GitHub Flow, GitFlow, release branches, and monorepo with diagrams, when-to-use, common problems, AIDLC worktree mapping (`base`/`target`/`strategy`), and parallel-Bolts notes. Cross-linked with the existing `cicd-patterns.md` § "Branch Strategies" so the two files stay coherent as the deeper menu (this) vs the CI-flow context (cicd-patterns)
* `## Mandated` and `## Forbidden` headings appended to `.claude/rules/aidlc/guardrails/project-guardrails.md`. Mirrors the heading shape of `org-guardrails.md`. Empty under this release; populated by the practices-discovery affirmation step
* Two markdown-section helpers added to `.claude/tools/lib.ts`: `extractMarkdownSection(content, heading)` returns the prose between `## Heading` and the next `## ` heading or EOF (empty string when absent); `appendUnderHeading(content, heading, newContent)` inserts before the next `## ` heading (throws when absent). Both pure-string functions; consumed by the practices-discovery affirmation copy under guardrail headings and the orchestrator stance lookup in `practices/team.md`
