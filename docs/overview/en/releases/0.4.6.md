## [0.4.6] - 2026-05-27

Ships the data-plane substrate for the steering loop: a per-workflow `runtime-graph.json` accumulator that fires deterministically on every approval gate. `runtime-graph.json` is the data-plane mirror of `stage-graph.json`, populated by walking `audit.md` + per-stage `memory.md` files. Three downstream consumers now have a stable surface to read from: the gate ritual (silent-diary-skip detection via `memory_entries` count), the doctor (diary-discipline metric via `MEMORY_EMPTY` rows), and v0.10.0's cross-workflow observer (pattern detection across many runs).

The compile is hook-driven, never LLM-tool-coupled. A new PostToolUse hook on the `Bash` matcher fires on every `bun aidlc-(state|jump|bolt|utility).ts` invocation that appends a transition-class audit row (`GATE_APPROVED | STAGE_STARTED | AUDIT_MERGED | WORKFLOW_COMPLETED`); the orchestrator's actual subprocess invocation is the deterministic anchor, regardless of what the LLM does next. `WORKFLOW_COMPLETED` is in the transition set so the final-stage approve fires the compile (otherwise `handleCompleteWorkflow`'s 5-row emit would never record the final stage as approved). v0.4.0-backfill: stages without a `memory.md` file get `memory_entries: null` and emit no `MEMORY_EMPTY` row, distinguishing "never tracked" from "tracked and empty" so v0.4.x users don't see an audit storm on first post-upgrade workflow.

* `aidlc-claude-code/.claude/tools/aidlc-runtime.ts` (new) — `compile` walks audit + memory.md to materialise `aidlc-docs/runtime-graph.json`; chronological `STAGE_STARTED ↔ STAGE_COMPLETED` pairing yields `outcome: "approved" | "pending" | "failed"` per row; emits `MEMORY_EMPTY` for zero-entry approved stages (per audit-format §13). `read <stage-slug>` prints one row for debug. Both subcommands respect `CLAUDE_PROJECT_DIR`.
* `aidlc-claude-code/.claude/tools/aidlc-lib.ts` — new `parseMemoryHeadings()` export. Pure function. Counts non-blank lines under each of the four canonical §13 H2 headings (`Interpretations`, `Deviations`, `Tradeoffs`, `Open questions`); BOM/CRLF tolerant; fence-aware via toggle walker; never throws on missing headings. Single source of truth shared by compile, gate ritual, and lifecycle.
* `aidlc-claude-code/.claude/hooks/aidlc-runtime-compile.ts` (new) — PostToolUse Bash-matcher hook. Filter pipeline: TTY guard → JSON parse → command regex → audit-existence guard → heartbeat → tail-read last 3 audit blocks → transition-event regex → Test-Run extract → `spawnSync` dispatch. `aidlc-runtime.ts` excluded from the matcher (recursion guard at command level); `MEMORY_EMPTY` excluded from the event regex (recursion guard at content level). Heartbeat at `aidlc-docs/.aidlc-hooks-health/runtime-compile.last` for `--doctor` silent-failure detection.
* `aidlc-claude-code/.claude/skills/aidlc/SKILL.md` — new PostToolUse `Bash` matcher block registers the runtime-compile hook alongside the existing `Write|Edit` (audit-logger) and `TaskUpdate` (sync-statusline) matchers.
* `aidlc-claude-code/.claude/knowledge/aidlc-shared/audit-format.md` — `MEMORY_EMPTY` Emitter cell flips from `Reserved` to `tools/aidlc-runtime.ts compile`. Five sensor-event rows (`SENSOR_FIRED`, `SENSOR_PASSED`, `SENSOR_FAILED`, `SENSOR_BUDGET_OVERRIDE`, `GUARDRAIL_LOADED`) stay reserved.
* `aidlc-claude-code/.claude/CLAUDE.md` — gitignore list extended with `aidlc-docs/runtime-graph.json` (mirrors v0.4.0 `.aidlc-recovery.md` precedent — generated artefact, not intended for commit).
* `docs/reference/19-runtime-graph.md` (new) — chapter documenting schema (locked TS interface), compile lifecycle, outcome enum + chronological pairing rule (re-jump handling), `MEMORY_EMPTY` semantics + idempotency, v0.4.0 backfill rule, snapshot + suffix-replay recovery model with freshness caveat for pending rows, parallel-Bolt mid-flight recovery deferred.
* `docs/reference/18-plane-architecture.md` — cross-link added from the data-plane substrate paragraph to chapter 19.
* `tests/unit/t88-parse-memory-headings.sh` (new, 18 tests) — pure-function coverage for `parseMemoryHeadings()`.
* `tests/feature/t90-runtime-compile.sh` (new, 29 tests) — `aidlc-runtime.ts compile` behavioural contract, including `--init --force` re-init filtering (latest WORKFLOW_STARTED wins, prior-workflow rows discarded), ISO-second collision deterministic ordering, the approved+non-zero negative case, MEMORY_EMPTY re-emit suppression (exactly one per (slug, gate-completion) tuple), re-approve still-empty fresh-emit, and schema nullability on instance-bearing parent rows.
