## [0.6.12] - 2026-06-13

Adds the Codex CLI distribution to the one-core-three-harnesses build: `harness/codex/` (manifest + `emit.ts` + the authored orchestrator skill and `aidlc-codex-adapter.ts`) regenerates `dist/codex/` from the shared `core/` via `bun scripts/package.ts codex`. emit.ts owns the Codex-specific surfaces no declarative row can express: `config.toml`, `hooks.json`, the hook trust pre-seed, the AGENTS.md merge, the 11 agent TOML transpositions (model map), and the `.agents/skills/` tree (orchestrator + runners + session skills, each with the implicit-invocation guard). Install Codex by copying `dist/codex/` into your project.

* `bun scripts/package.ts` now regenerates `dist/codex/` alongside claude + kiro; `--check` drift-guards all three. New `bun scripts/package.ts codex trust --project <dir>` prints the hook-trust entries for `$CODEX_HOME/config.toml`.
* The packager now reads renamed rule dirs at compile time (`AIDLC_RULES_DIR`) and realigns the compiled graph's rule paths — fixes empty `rules_in_context` in the kiro and codex distributions (their stage graphs now carry `.kiro/steering/` and `.codex/aidlc-rules/` rule paths).
* New tests: `t149-codex-hook-adapter` (12-case adapter contract), `t150-codex-packaging` (rename, hooks-wiring, trust-hash recipe, openai.yaml guards). The codex-exec journey ships as e2e gated on `AIDLC_CODEX_EXEC_LIVE=1` + codex ≥ 0.139.0.
* No change to the Claude distribution — `dist/claude/.claude/` stays byte-identical.
