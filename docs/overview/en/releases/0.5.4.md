## [0.5.4] - 2026-06-01

Removed the silently-ignored `allowedTools` frontmatter field from all 11 agents. Agents intentionally inherit the full session toolset and are restricted only by `disallowedTools: Task`; adding an optional `tools:` allowlist is the documented way to narrow an agent (which drops inherited MCP access unless `mcp__<server>__<tool>` ids are listed). No upgrade action required.

* The `allowedTools` field is removed across the 11 agent files, and the docs are reframed to the inherit-all model.
* Agent files now carry an inline note documenting inherit-all / `tools:`-to-restrict / `disallowedTools: Task`.
* The t04 frontmatter guard is inverted to assert the ignored field stays absent.
