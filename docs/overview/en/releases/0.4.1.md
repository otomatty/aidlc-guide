## [0.4.1] - 2026-05-20

Pre-registers the audit taxonomy slots that v0.5.0's deterministic-sensor system will fill. Five new event types appear in the registry with `Reserved` Emitter cells; no emitters ship in this release. Downstream work can now import the new event constants without colliding on the registry's pinned count — `tests/unit/t28-audit-event-sync.sh` would otherwise force serialised access to `VALID_EVENT_TYPES`, `audit-format.md`, and `12-state-machine.md` across the v0.5.0 sensor work. The reserved cells point at the dispatcher (`aidlc-sensor.ts`) which owns the four `SENSOR_*` emissions; `GUARDRAIL_LOADED` is reserved for the paired-coverage doctor row. Audit taxonomy grows 55 → 60 events across 15 → 16 categories. The new Sensor Events category reserves capacity for four Fowler-aligned deterministic sensors (`required-sections`, `upstream-coverage`, `linter`, `type-check`); `weasel-words` is deferred to v0.9.0's LLM-judge sensor mix.

* `aidlc-claude-code/.claude/tools/aidlc-audit.ts` — `VALID_EVENT_TYPES` and `EVENT_HEADINGS` both grow by five new entries: `SENSOR_FIRED`, `SENSOR_PASSED`, `SENSOR_FAILED`, `SENSOR_BUDGET_OVERRIDE`, `GUARDRAIL_LOADED`. The Sensors block carries a pre-registration comment matching the v0.4.0 Merge Dispatch precedent so future maintainers reading the .ts file see the same forward-note discipline as future readers of audit-format.md
* `aidlc-claude-code/.claude/aidlc-knowledge/shared/audit-format.md` — heading bumped to `## Event Registry (60 events, 16 categories)`; new `### Sensor Events (5 events)` section appended after Merge Dispatch with the five rows. `Emitter` cells are `Reserved` for the four `SENSOR_*` events and for `GUARDRAIL_LOADED`. `tests/feature/t48-audit-event-emitters.sh`'s line-101 case-insensitive `Reserved` skip preserves t48 green during the wait for emitters
* `docs/reference/12-state-machine.md` — count-pin and parity-mirror updated. Heading sentence now reads "60 events across 16 categories"; new `### Sensors` registry section appended after Merge dispatch with the same five rows in the chapter's `Event | Emitter | Trigger` shape. v0.4.0's md↔md parity invariant (audit-format.md and 12-state-machine.md ship the same rows) is preserved
* `tests/unit/t28-audit-event-sync.sh` — assertion bumped from `assert_eq 55` to `assert_eq 60`; pin label updated to "VALID_EVENT_TYPES.size === 60 (v0.5.0)"
* Doc count-pin sweep across 11 surfaces: `README.md`, `docs/guide/{00-introduction, 07-knowledge, 09-state-and-audit, glossary}.md`, `docs/reference/{00-overview, 01-architecture, 06-hooks-and-tools, 07-knowledge-system, 12-state-machine, 15-stability-policy}.md`. The `### 60-event taxonomy` table in `09-state-and-audit.md` gains a new `Sensors | 5 | SENSOR_FIRED, SENSOR_PASSED, SENSOR_FAILED, SENSOR_BUDGET_OVERRIDE, GUARDRAIL_LOADED (pre-registered for v0.5.0)` row. `15-stability-policy.md`'s count-pin example updates from `assert_eq 55` to `assert_eq 60`
