# aidlc-workflows の更新履歴と改善点

このページは AIDLC Guide がまとめた日本語の改善点ガイドです。公式 CHANGELOG の全文訳ではありません。各版のリンクから、同梱した原文の変更内容・修正・移行手順を確認できます。

[すべての更新履歴を開く](changelog.md)

## 2.8.0 で変わったこと

2026年9月8日公開の [2.8.0](releases/2.8.0.md) は、2.7.x の改善をまとめたリリースです。2.7.2 から実行動作は変わりません。State Version は 8、ステージ数は 33 のままです。

| 版・公開日 | 改善前の問題・変更の目的 | 改善後の動作 |
| --- | --- | --- |
| [2.8.0](releases/2.8.0.md) · 2026-09-08 | 2.7.x の修正を新しい基準版としてまとめる | 各環境のバージョン表示と配布物を 2.8.0 に統一。2.7.2 の既存記録に移行は不要 |
| [2.7.2](releases/2.7.2.md) · 2026-09-07 | リリースのタグと配布物の出所を結び付ける | タグ・バージョン・コミットを照合し、配布物名に版数を含める。インストーラーは出所と SHA-256 を検証し、対応する GitHub CLI があれば署名付き証明も検証 |
| [2.7.1](releases/2.7.1.md) · 2026-09-01 | ソロ作業で計画を承認しても、ターン終了時に承認が無効になりコード生成へ進めない | Stop hook の読み取り専用確認が承認状態を書き換えなくなり、承認後にコード生成を開始できる |

## 2.8.0 へ更新するとき

公式インストーラーでは `install.sh --version 2.8.0` または `install.ps1 -Version 2.8.0` を指定します。手動コピーの場合は `aidlc-runtime-2.8.0.tar.gz` 内の `runtime/<harness>/` を使います。詳細は[セットアップガイド](guide/01-getting-started.md)と[2.8.0 の原文](releases/2.8.0.md)を確認してください。

2.7.2 の既存記録には移行が不要です。それより古い版からの更新では、間にある各版の Upgrade / Breaking / migration の記述も確認してください。2.8.0 の概要だけでは、以前の一度限りの移行手順を代替できません。

表示している版数は AIDLC Guide に同梱したドキュメントの版数です。対象ワークスペースへのインストール済みバージョンや、AIDLC Guide 拡張自体のバージョンとは別です。
