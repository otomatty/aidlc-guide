# エージェント詳細

ドメインエージェントごとに 1 ページずつ用意しています。担当領域、主導・支援するステージ、読み込むナレッジ、そして連携方法を確認できます。フル編成は 14 エージェントで、11 のドメインエージェント、2 つのレビュー専任エージェント、そして adaptive-workflows のコンポーザーから成ります。この索引が扱うのは、ステージの作業を実行する 11 のドメインエージェントです。

レビュー専任エージェントは独立したプロダクトレビューとアーキテクチャレビューを行い、コンポーザーは適応的なステージ計画の提案と再編成を担います。3 つのロールグループすべてと、狭い専門家 30 人ではなく幅広いドメインエージェント 11 人にした設計思想は [エージェント](../06-agents.md) 章を参照してください。フロントマター契約、ツール許可リスト、完全な比較マトリクスは、開発者リファレンスの [エージェントリファレンス](../../reference/agents/README.md) を参照してください。

| # | エージェント | ドメイン |
|---|-------|--------|
| 1 | [aidlc-product-agent](product-agent.md) | 要件、スコープ、ユーザーストーリー、市場調査 |
