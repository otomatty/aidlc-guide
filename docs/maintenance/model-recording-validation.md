# モデル情報の検証範囲

現在の実装は、既存の `aidlc/.aidlc-sessions/usage-ledger.json` を読み取り、選択した作業のステージ別モデルを表示するものです。実行中のモデルを取得して記録する処理、モデル情報だけの共有用ファイルを保存する処理は未実装です。

## 実装済みのテスト

| 対象                      | 検証内容                                                                                                                                                                                                                                                                                      | テスト                                                       |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |

連携テストは通信部分を同一プロセスのAPI呼び出しに置き換えています。モデル実行環境のフック、実際のHTTP通信、VS Code拡張ホストは起動していません。記録ファイルはテストが用意した入力です。

「担当」はステージ全体の累計使用モデルを表示します。レビュワー・補助個別の使用実績はないため、それぞれ定義があるステージだけにバッジを表示し、値はデフォルトです。バッジは横並びで、画面幅に応じて折り返します。

## 自動記録の実装時に必要な検証

以下は未実装の機能に対する受け入れ条件です。今回のテスト成功には含めません。

- 実行側から取得したモデルIDを、対象の作業・ステージ・担当またはレビュワーに対応付けて保存する。
- モデル変更、再実行、複数のレビュワーを区別し、取得できないモデルを推測して保存しない。
- 同じイベントの再送で重複せず、同時書き込みで記録が欠落しない。
- 書き込み途中の終了、再起動、保存エラーから復旧する。
- 共有ファイルには必要なモデル情報だけを含め、会話本文・認証情報・端末固有のパスを含めない。
- Gitで共有したファイルを別のチェックアウトで読み取り、同じ表示になる。
- 実際の拡張ホストで、モデル取得から保存・再読み込み・画面反映までを確認する。
