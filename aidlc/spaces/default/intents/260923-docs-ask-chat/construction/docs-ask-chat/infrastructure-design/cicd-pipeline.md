# 届け方

別の配備パイプラインは作らない。品質ゲートは、いまの `package.json` の `check` のままである。

| 段階 | ゲート |
| --- | --- |
| テストを先に書く | チャットの UI テストと、ask / job / cancel / evidence の契約テストが、実装の前に失敗する |
| `bun run check` | lint、型、テスト、カバレッジ下限。呼び出し側は項目を独自に列挙しない |
| `main` へ squash-merge、または git タグ | これがリリース。staging も production も無い |

戻し方は `git revert`、または直前のタグである。ブルーグリーン、カナリア、フィーチャーフラグは置かない。

秘密情報は CI に置かない。VSIX に秘密情報、`.env`、`aidlc/` のランタイム状態を含めない、という既存の衛生のままである。
