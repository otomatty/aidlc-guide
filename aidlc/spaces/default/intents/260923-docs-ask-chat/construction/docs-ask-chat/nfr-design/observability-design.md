# 観測の実現

遠隔の計測は足さない。見る場所は画面の短い失敗表示と、ローカルの `bun run check` である。

| ID | 実現機構 | 非該当のとき |
| --- | --- | --- |
| NFR1.1 | チャット画面の UI テストを dashboard の docs 機能のテストとして書き、`package.json` の `check` から外さない | — |
| NFR1.2 | ask / job / cancel / evidence の契約テストを `api-core` の既存 docs-qa ルートテストの並びに足し、同じ `check` から外さない | — |
| NFR1.3 | それらのテストを先に書き、失敗を見てから実装する。ランナーは Vitest のまま | — |

分散トレース、相関 ID、遠隔ダッシュボード、警報の当番は置かない。失敗は入力のそばの短いメッセージである。再訪のきっかけは、ローカル以外へログを送る決定である。
