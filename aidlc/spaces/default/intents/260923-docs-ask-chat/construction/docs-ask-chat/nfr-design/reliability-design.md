# 信頼性の実現

プロセスが止まれば画面も止まる。残すのは会話である。

| ID | 実現機構 | 非該当のとき |
| --- | --- | --- |
| NFR3.1 | ターンと書きかけは `ExtensionContext.globalState` から戻す。件数の上限は置かない。溢れたら捨てる、という規則は無い | — |
| NFR4.1 | 進行中の 1 件は、完了、既存のキャンセル、または失敗で終わる。失敗のあと次を送れる。ジョブ本体はプロセス内のまま | — |

サーキットブレーカ、再試行のバックオフ、複製、フェイルオーバーは置かない。再訪のきっかけは、質問ジョブ自体を再起動後も残す決定である。
