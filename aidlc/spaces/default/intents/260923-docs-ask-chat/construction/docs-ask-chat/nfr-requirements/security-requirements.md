# セキュリティ要件

新しい認証は足さない。境界は、ホストモードの拒否と、このマシンに閉じた保存である。

| ID | 要件 | 破ったときの観測 |
| --- | --- | --- |
| NFR3.1 | 会話は、拡張ホストがこのインストール用に持つローカル保存に置く。ワークスペースのファイルには書かない | ワークスペースのファイルが増える、または会話がそこに残る |
| NFR3.2 | 保存のためにクラウドへ送らない | 永続化の通信がクラウドへ出る |
| NFR5.1 | ホストモードでは、質問の送信、取得、キャンセル、根拠の取得を拒否する | それらのいずれかが成功する |

既存のまま残すもの: 質問の成否は `DocsQaResult<T>`、同梱ドキュメントの読取は `guardPath`、VSIX に秘密情報・`.env`・`aidlc/` のランタイム状態を含めない。データベースは新設しない。
