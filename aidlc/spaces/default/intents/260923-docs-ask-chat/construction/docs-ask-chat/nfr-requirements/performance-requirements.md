# 性能要件

応答時間の新しい予算は置かない。質問の待ち時間は、いまと同じローカル CLI が支配する。この変更で足すのは、品質ゲート上のカバレッジである。

| ID | 要件 | 測り方 |
| --- | --- | --- |
| NFR2.1 | docs-qa の分岐カバレッジは 70% 以上 | `bun run check` のカバレッジ |
| NFR2.2 | 既存の分岐 95% の下限は、その対象パスのまま残す | 同じカバレッジレポートで、既存対象が 95% を下回らない |
| NFR2.3 | ワークスペース全体の行カバレッジ 80% を維持する | 同じカバレッジレポートの行 |

待ち時間に秒数の目標は付けない。遅い応答を、この変更の新しい失敗条件にしない。
