# 観測要件

新しい計測基盤や遠隔のダッシュボードは置かない。見る場所は、画面の短い失敗表示と、ローカルの品質ゲートである。

| ID | 要件 | 測り方 |
| --- | --- | --- |
| NFR1.1 | チャット画面の UI テストを `bun run check` に含める。欠けると通さない | `bun run check` |
| NFR1.2 | 契約テストを `bun run check` に含める。欠けると通さない | `bun run check` |
| NFR1.3 | 先に失敗するテストを書き、それから実装する | テストが実装より先に失敗すること |

失敗した質問は、入力のそばの短いメッセージで分かる。吹き出しにはしない。遠隔へログを送る要件は置かない。
