# ペルソナ

主人公はひとりである。ドキュメントに質問する人だけを描く。ホストモードで質問できない状態は、この人の拒否として扱う。別の主人公にはしない。

## 質問者

- **役割**: 同梱ドキュメントを読みながら、AI に質問する人。
- **目的**: 質問したあとチャット画面で続きを聞き、根拠の記事へ移って戻れること。
- **困っていること**: いまはホームに回答カードが積み上がり、専用のチャット画面へ移らない。再起動するとやり取りが消える。
- **状況**: ドキュメントのホームから質問を始め、チャットと記事を行き来する。このインストール上の会話は一つである。

## 優先

質問者が唯一の主人公である。他の役割は、この変更の物語には置かない。

## 出典

`requirements.md` の FR1 から FR6。`business-overview.md` のドキュメント質問。`component-inventory.md` の Docs ホーム。`team-practices.md` のローカル専用。
