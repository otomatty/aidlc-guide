## Question 1

物語の主人公は誰ですか。ホストモードでは質問できないことが、既に要件にあります。

A. ドキュメントに質問する人、ひとり
B. 質問する人と、ホストモードで質問できない人、のふたり
X. Other (please specify)

[Answer]: A. ドキュメントに質問する人、ひとり

## Question 2

物語はどの単位で分けますか。細かく分けると受け入れが操作ごとになり、粗く分けると一つの流れが一本になります。

A. 操作の流れごと（入口、チャットでの続き、保存、引用から戻る）
B. 要件の塊ごと（入口、チャット、残り方、履歴、記事、入力をそれぞれ一本）
X. Other (please specify)

[Answer]: A. 操作の流れごと（入口、チャットでの続き、保存、引用から戻る）
