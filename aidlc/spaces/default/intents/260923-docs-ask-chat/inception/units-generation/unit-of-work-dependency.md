# 塊の依存

塊は一つである。塊同士の矢印は無い。実装の順番も、先に作るべき道筋も、ここには書かない。根拠は `requirements.md` と `stories.md`。部品一覧（`components.md`）と決定記録（`decisions.md`）は無い。

## 依存の形

```text
docs-ask-chat
```

- `docs-ask-chat` から他の塊への依存は無い。
- チャット画面がいまの質問の送受信を使う関係は、この塊の内側である。別の塊にはしない。
- 質問を処理する側が会話の保存を持つ関係も、この塊の内側である。

## 結合点

| 内側の関係 | 内容 |
| --- | --- |
| チャット画面 → いまの質問の送受信 | 画面は既存の質問経路を呼ぶ。新しい口は増やさない。 |
| 質問を処理する側 → このマシン上の会話 | このインストールの会話を一つ持つ。画面はそれを表示し、質問を送る。 |
| 画面 → 記事 | 引用は記事へ移り、チャットへ戻る。分割表示はしない。 |

塊が一つなので、同時に進められる別塊は無い。塊の内側をどう並行するかは、ここでは決めない。

循環は無い。

