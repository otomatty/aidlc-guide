# Units Generation — Questions

部品の一覧は作りませんでした。チャット画面も、閉じたあとも会話が残ることも、いまのドキュメント質問の変更です。すでに決まっていることは聞き直しません。画面と質問処理は、いまのダッシュボードのドキュメント機能と、いまの質問の送受信に載せる。新しい送受信の口や、画面から別の読み込み口は増やさない。配置は、このマシン上の拡張の中に閉じ、独立したサービスとしては出さない。データベースは使わない。実装の順番は、このあと別の段で決める。

## Question 1

作業の塊をどう切りますか。塊は、あとで別々に設計できる範囲です。ここでは、どれを先に作るかは決めません。

A. 一つにまとめる。チャット画面と、質問の履歴・保存・送信中の制御を、同じ作業にする
B. 二つに分ける。チャット画面と、質問側（直近 8 ターンを渡す、このマシンに会話を残す、同時に一つだけ処理する）を別の作業にする
C. 三つに分ける。チャット画面、会話の保存、質問の送受信をそれぞれ別の作業にする
X. Other (please specify)

[Answer]: A. 一つにまとめる。チャット画面と、質問の履歴・保存・送信中の制御を、同じ作業にする

## Question 2

A. 質問を処理する側が、このインストールの会話を一つ、このマシン上に持つ。チャット画面はそれを表示し、質問を送るだけ
B. チャット画面が、このマシン上の会話を持つ。質問を処理する側は、送られた質問に答えるだけ

[Answer]: A. 質問を処理する側が、このインストールの会話を一つ、このマシン上に持つ。チャット画面はそれを表示し、質問を送るだけ
