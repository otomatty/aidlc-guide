# 作業の塊

チャット画面と、質問の履歴、このマシン上の会話の保存、送信中の制御を、一つの作業にする。部品一覧（`components.md`）と決定記録（`decisions.md`）は、部品の切り出しを行わなかったため無い。根拠は `requirements.md` と `stories.md`。

ここでは実装の順番も、先に作るべき道筋も決めない。

### 持つもの

- ホームの質問入口からチャット画面へ移ること。ホームに回答カードは積まない。
- チャット画面での続きの質問、直近 8 件の完了ターンを渡すこと、2000 字の上限、応答が終わるまでの送信禁止、いまのキャンセル。
- このインストールの会話を一つ、このマシン上に残すこと。持ち主は質問を処理する側。チャット画面は表示と送信だけ。画面の一覧は、モデルへ渡す 8 件では切り詰めない。
- 引用から記事へ移り、チャットへ戻ったとき、会話と書きかけの文が残ること。分割表示はしない。
- ホストモードでは、入口とチャットの送信、取得、キャンセル、根拠の取得を拒否すること。

### 制約

- データベースは使わない。保存はクラウドへ送らない。
- 新しい送受信の口や、画面から別の読み込み口は増やさない。画面は、いまの質問の送受信を使う。
- `dashboard` は `reader-core` を import しない。
- コンテンツローダは `api-core` / `official-docs` のまま。
- 会話は記事ごと、locale ごとには分けない。
