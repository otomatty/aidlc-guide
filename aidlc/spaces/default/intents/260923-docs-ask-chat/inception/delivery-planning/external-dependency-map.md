# 外の依存

通し（Bolt）は、一塊の作業を一度に作り、動くところまで持っていく区切りである。この変更を止める、チームの外の待ちは無い。

## 対応

| 外の待ち | 持ち主 | かかる時間 | 止める通し | 遅れたとき |
| --- | --- | --- | --- | --- |
| 無し | — | — | — | — |

クラウドへ送る保存、他チームの引き渡し、外部 API の窓口、承認のリードタイムは無い。会話の保存はこのマシン上で完結する（`requirements.md`）。契約（`contract-summary.md`）は無い。部品一覧（`components.md`）も無い。画面は、いまの質問の送受信を、同じ塊の内側で使う（`unit-of-work.md`）。
