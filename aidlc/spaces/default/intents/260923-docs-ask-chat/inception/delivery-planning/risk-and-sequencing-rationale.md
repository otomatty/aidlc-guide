# 順序の理由

通し（Bolt）は、一塊の作業を一度に作り、動くところまで持っていく区切りである。点数で順位を付ける方式（価値と急ぎとリスクを大きさで割る）は使わない。順位を付ける対象が一つだからである。

## なぜ一つの通し

塊 `docs-ask-chat` は一つで、他の塊への依存は無い（`unit-of-work-dependency.md`）。チャット画面、履歴、このマシン上の保存、送信中の制御は、同じ通しで作る。依存の順から外れる並べ替えは無い。

骨格用の最初の通しは行わない。B1 は通常の通しである（`team-practices.md`）。

## 通しの中で先に確かめること

先に潰す心配は、アプリを閉じたあとに会話が残ることである（`requirements.md` の FR3、`stories.md` の US3.1）。これは別の通しには分けない。B1 の中で、その残り方を先に確かめる。

価値の順でも、リスクだけの順でも、通しを並べてはいない。通したが一つだからである。
