# 画面

`wireframes.md` と `user-flow.md` は、このワークフローでは作られていない。画面は `stories.md` と `requirements.md` から作る。見た目は `team-practices.md` の既存 Docs UI を踏襲する。

## ホーム

保存済みの会話が無いときだけ、ドキュメントはホームから始まる。質問の入口だけがある。回答カードは無い。

```
[ ドキュメント ]
[ 質問を入力 ____________ ] [送信]
2000字まで
```

## チャット

保存済みの会話があるとき、ドキュメントを開くとこの画面から始まる。広い幅では会話を中央の読みやすい列に寄せる。狭い幅では会話と入力を縦に積む。

```
[ チャット ]
  質問者: …
  回答: …  [引用]
[ 短い失敗メッセージ ]
[ 質問を入力 ____________ ] [送信]
```

送信中は送信ボタンが止まる。失敗は吹き出しではなく、入力のそばの短いメッセージである。引用を選ぶと記事画面へ切り替わる。チャットと記事を並べない。

## 記事

既存の記事画面である。チャットへ戻る操作がある。戻ったとき、会話と書きかけの文が残る。

## 流れ

ホーム（会話が無いとき）→ 送信 → チャット。会話があるときは最初からチャット。引用 → 記事 → チャットへ戻る。
