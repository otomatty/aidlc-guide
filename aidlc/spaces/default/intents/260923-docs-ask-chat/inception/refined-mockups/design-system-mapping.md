# デザインシステムの対応

新しい見た目の体系は足さない。dashboard の既存部品を使う。`team-practices.md` のとおり、チャットは `features/docs` に置く。

| 画面の要素 | 既存の置き場 |
|---|---|
| ホームの質問入口 | いまの質問フォーム。回答カード列は出さない |
| チャットの会話 | 同じ Docs シェル内の新しい面。回答カードの積み上げは使わない |
| 送信と送信中の停止 | いまの質問パネルの送信ボタン |
| 失敗の短いメッセージ | いまの質問パネルの失敗表示。吹き出しにはしない |
| 引用から記事 | 既存の記事画面と、回答へ戻る導線 |
| 幅 | 広いときは中央列、狭いときは縦積み。色だけで状態を伝えない |

`requirements.md` の FR1 から FR6 は、上の行で画面に割り当てた。
