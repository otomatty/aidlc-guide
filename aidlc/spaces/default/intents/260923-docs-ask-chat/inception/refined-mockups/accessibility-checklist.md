# アクセシビリティ

目標は WCAG 2.1 AA である。状態は色だけに依存しない。

| 項目 | 条件 |
|---|---|
| 名前 | 質問入力、送信、チャットへ戻る、には見えるラベルがある |
| 焦点 | ホーム、チャット、記事の順で、キーボードだけで移動できる |
| 送信不可 | 2000字超、空、応答中、ホストモードでは、ボタンが無効であることと理由がテキストで分かる |
| 失敗 | 短いメッセージは入力のそばにあり、色だけではない |
| 待ち | 送信中であることがテキストで分かる |
| 幅 | 狭い幅でも、会話・入力・送信が縦に読め、隠れない |
| 記事から戻る | 戻る操作に名前があり、戻ったあと焦点はチャットの入力に戻る |

根拠は `stories.md` の四つの流れと、`requirements.md` の画面上の条件である。
